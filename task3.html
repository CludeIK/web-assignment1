Sir Tim Berners-Lee

The Inventor of the World Wide Web

About Tim Berners-Lee

Sir Timothy John Berners-Lee was born on June 8, 1955, in London, England. He is an English computer scientist best known as the inventor of the World Wide Web, the HTML markup language, the URL system, and HTTP. In 1989, while working at CERN, he proposed an information management system that successfully implemented the first communication between a Hypertext Transfer Protocol (HTTP) client and server via the Internet. Today, he is the director of the World Wide Web Consortium (W3C), which oversees the continued development of the Web.

Important Events

  1. 1955: Born in London, England.
  2. 1976: Graduated from Queen's College, Oxford, with a degree in physics.
  3. 1989: Proposed the World Wide Web project at CERN.
  4. 1990: Created the first web browser and web server.
  5. 2004: Knighted by Queen Elizabeth II for his pioneering work.

Key Contributions

  • Invention of HTML (HyperText Markup Language).
  • Creation of URI/URL (Uniform Resource Identifier).
  • Development of HTTP (HyperText Transfer Protocol).
  • Founding the World Wide Web Consortium (W3C).
