# Assignment 1: HTML & CSS Basics

## Description
This project is the first individual assignment for the **Web Technologies** course at Astana IT University. It demonstrates fundamental knowledge of HTML structure, CSS styling, page layouts, and form creation.

## Structure
- **Task 1:** Personal webpage with profile card, lists, and images.
- **Task 2:** Simple webpage layout built using `<div>` elements and CSS `float` (no Flexbox or Grid).
- **Task 3:** Tribute page dedicated to Sir Tim Berners-Lee using Google Fonts and custom styling.
- **Task 4:** Student grades table and a styled feedback form.
